# shared/service

| File                    | Purpose                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `api.service.ts`        | `ApiService`: all backend calls (base `BACKEND_API_URL = http://<expressBackendHost>:<expressBackendPort>/api` from `src/environments`). Data files: list/filter (paged, optional `onlyMetadata`), get, create, update, delete, attach a raw file (`createDatafileWithFile` = create + `POST /datafile/:id/attach`), dataset import from file (`POST /datafile/fromFile`, multipart: `file`, `dataset`, optional `tags` (comma separated), `description`, `steps` for CERv2). Journeys: list/filter, get, create, update (strips `_id`, timestamps, `__v`), delete. Geocoding via Nominatim: `geocodeAddress(address)` → `[lon, lat]` or `null`, `getAddress("lat, lon")` → display name or `null`. |
| `coordinate.service.ts` | `CoordinateService`: `transformToLongLat(coord)` (EPSG:3857 → EPSG:4326) and a `coordinate$` stream of clicked map coordinates. Not `providedIn: root`; provided by `SharedModule` and `MapModule`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `dialog.service.ts`     | `DialogService.openDisplayDataDialog(datafile)` opens `DataDisplayDialogComponent`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |

Original author of `coordinate.service.ts` and of the address lookup in `api.service.ts` (`geocodeAddress`, `getAddress`): Florian Jäger (TCF-5 PR #66, TCF-90 PR #103).

Gotchas: paging parameters are part of the path (`/limit=10&skip=0`), not a query string, matching the public-api routes. The full endpoint list is in `frontend/README.md`.
