# journey/services

`JourneyService` (not `providedIn: root`; provided by `JourneyComponent`) holds the state of one journey as RxJS streams.

| Member                                                                                                             | Meaning                                                                                                                                                                                                                                 |
| ------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `journey$`                                                                                                         | Current `Journey` (or `null`).                                                                                                                                                                                                          |
| `selectedCollection$`                                                                                              | Collection whose filters are shown/edited.                                                                                                                                                                                              |
| `excludedDataFiles$`                                                                                               | `Set` of data file ids the user deselected (saved as `excludedIDs`).                                                                                                                                                                    |
| `collectionsData$`                                                                                                 | One observable per collection with `CollectionData` = collection + fetched files + colour (`src/util/colors.ts`) + selected file ids. Re-fetches a collection on `reloadSelectedCollection()`, re-emits on `triggerCollectionChange()`. |
| `loadJourney(id \| null)`                                                                                          | Loads from the backend or creates an empty journey; applies `excludedIDs`, selects the first collection; returns an observable `true`/`false`.                                                                                          |
| `addCollection()` / `deleteCollection(c)` / `selectCollection(c)`                                                  | Collection management (`Collection #<n>` naming with the first free number).                                                                                                                                                            |
| `selectDataFiles(...)` / `deselectDataFiles(...)`, `allDataFilesSelected$(...ids)`, `fewDataFileSelected$(...ids)` | Selection state.                                                                                                                                                                                                                        |
| `addMapFilters(filters)`                                                                                           | Synchronises the selected collection's map filters with the filters drawn on the map.                                                                                                                                                   |
| `saveJourney()`                                                                                                    | Opens `ContinueJourneyDialogComponent`, then `POST /api/journey` with the current user as author.                                                                                                                                       |
| `download()`                                                                                                       | `DownloadService.downloadJourney` with the current exclusions.                                                                                                                                                                          |

Gotchas:

- Files that disappear from a collection after a filter change are automatically deselected (subscription in the constructor; uses `delay(0)`).
- Deleting the selected last collection now selects `null` (it used to throw).
- Uses `ApiService`, `DownloadService`, `MatDialog`, `AuthService`.
